Fernwartungs-Tool herunterladen

Für die Fernwartung nutzen wir RustDesk. Lade dir die vorbereitete Version herunter und starte sie – eine Installation ist nicht nötig.

So geht's

  • Datei herunterladen und öffnen.
  • Windows zeigt beim ersten Start eventuell eine Warnung ("Windows hat den Computer geschützt"). Auf Weitere Informationen und dann Trotzdem ausführen klicken.
  • Mir die angezeigte ID und das Passwort durchgeben (z. B. per Telefon oder WhatsApp), damit ich mich aufschalten kann.
